Guide 01 · Resume building

Build a clear, evidence-based resume.

Use the resume template as a structure. Tailor one version to each job track, describe what you actually built, and export a clean PDF.

01

Choose one target role

Make a separate version for the role you want, such as Software Engineering, AI/ML Engineering, Data Engineering, or Data Science. Read the job description and prioritize matching experience you genuinely have.

02

Collect your facts first

Gather your name and contact links, education and dates, relevant skills, two or three substantial projects, experience, certifications, publications, and achievements. Check spelling, dates, and URLs before writing.

03

Write a focused summary

In two or three concise lines, connect your background to the target role. Mention your strongest relevant skills and the systems or projects you have built. Avoid generic claims and unsupported metrics.

04

Organize the resume sections

Use standard headings and a simple, readable layout:

  • Name, target role, contact details, LinkedIn, GitHub, portfolio
  • Professional summary and education
  • Technical skills grouped by type
  • Selected projects, with repository links
  • Experience, certifications, publications, achievements, if relevant
05

Describe projects with evidence

Use this pattern: action + technical method + purpose + verified result. Explain the problem, your contribution, technical decisions, and how you evaluated the result. Include a metric only if you can explain how it was measured.

06

Make your project repositories useful

Add a clear README, setup instructions, screenshots or a demo when useful, and reproducible steps. Include testing, security, database design, deployment, logging, or documentation when they are relevant to the work.

07

Tailor, export, and check

Use job-description keywords only when they accurately describe your experience. Keep text selectable and fonts readable. Open the exported PDF and check for page overflow, blank pages, broken links, and unsupported claims.

08

Prepare to discuss everything listed

Practice role-specific topics, problem solving, data structures and algorithms, core computer science, and SQL as appropriate. Be ready to explain project decisions, trade-offs, limitations, and possible improvements.

Before you apply

  • Tailor the resume to the role
  • Verify dates, links, and every claim
  • Use only real, measurable results
  • Check PDF layout and hyperlinks
  • Be ready to explain each listed skill
About compensation

A resume template can help present your experience. It cannot promise a particular salary or job offer.

Guide 02 · GitHub portfolio

Build your GitHub profile README.

Follow the guide from your GitHub portfolio PDF. The README appears at the top of your profile and points people toward your best work.

01

Open your GitHub profile

Check whether your profile already has a README. GitHub displays a profile README when a repository has the same name as your username and contains a README.md file.

02

Start a new chat in Claude

Open Claude in your browser and begin a new chat. Use the prompt from the guide as a starting point, then replace every placeholder with your own verified details.

Open Claude ↗
03

Ask for the README sections you need

Include your name, role, location, email, LinkedIn, portfolio, GitHub, and experience level. Ask for a short introduction, skills, featured projects, what you are learning, and contact details.

  • Optional: badges, skill icons, contribution graph, statistics, or streak
  • External images and statistics can change or become unavailable
  • Do not include tools, skills, projects, or results you cannot verify
04

Review the generated Markdown

Check every line, link, project description, and technology. Remove placeholders and any examples that are not true for you. Ask Claude to return only the complete README.md Markdown.

05

Copy the README into GitHub

Open the repository used for your profile README, edit README.md, replace its existing content with the reviewed Markdown, and preview the changes.

06

Commit and check your profile

Click Commit changes, then refresh your GitHub profile. Test the project, portfolio, LinkedIn, and email links from the rendered page.

Good README sections

  • Name, role, short introduction
  • About and technical skills
  • Three featured projects
  • Currently learning
  • GitHub and contact links
Keep it readable

Use a clean layout, concise writing, restrained badges, and projects with working repository or demo links.

Guide 03 · Resume to portfolio

Turn your resume into a recruiter-friendly website.

Use your resume as the source, ask an AI tool to organize it into a portfolio, then verify every section before you publish.

01

Prepare the source resume

Use your latest resume or profile as the source of truth. Check that the dates, skills, experience, projects, certifications, and links are current. Remove private information you do not want online.

02

Ask Claude to build the portfolio from those facts

Open a new Claude chat, upload your resume, and provide a clear prompt. Request a polished, responsive site with a hero, about section, skills, experience, project case studies, certifications, resume download, and contact links.

03

Review the result line by line

Compare the generated text with your resume. Remove invented companies, skills, projects, credentials, awards, and results. Check that every project link points to the right repository and that your contact links work.

04

Improve the portfolio for recruiters

Make projects easy to scan: explain the problem, your contribution, technologies, and a result you can substantiate. Use clear headings, accessible contrast, responsive layouts, and subtle motion that does not distract.

05

Preview on phone and laptop

Check navigation, spacing, text size, resume downloads, social links, and project links on both screen sizes. Keep the most relevant information easy to find.

06

Publish and verify the live page

Put the site files in your chosen hosting service, enable its publishing option, and open the public URL. Verify the live version itself, including its links and resume download, before sharing it.

07

Keep your resume and portfolio in sync

When something changes, update the source details and check both places. Your portfolio editor below updates the existing portfolio; it does not automatically rewrite a separate resume PDF.

Portfolio sections

  • Hero and clear role
  • About and skills
  • Experience and projects
  • Certifications or achievements
  • Resume download and contact links
